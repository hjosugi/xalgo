重み一覧

重みは「その行動の確率1.0あたり、スコアに何点入るか」を表す倍率です。値が大きい行動ほど、起こりやすさが同じでもスコアへの寄与が大きくなります。

重みの意味（例）

返信の重み 5.0、いいねの重み 0.5。
同じ P=0.02 でも、返信は 5.0 × 0.02 = 0.100、いいねは 0.5 × 0.02 = 0.010。返信はいいねの 10倍効く。

重要な注意: 重みは確率に掛かります。カウントに掛けると「報告1件 = いいね468件分」のような誤解になります（上流 README も否定）。

負の重み

負の重みは絶対値が大きく、起こりにくい行動（報告など）を強く抑制します。

10月に変わった3項目

click 0.4 → 0.3（クリックの価値を下げた）
cont_click_dwell_time 0.0 → 0.4（クリック後の滞在を評価するようになった）
not_interested −43.2 → −47.52（興味なしの抑制を強めた）

「クリックは減ったが、クリック後の滞在が新たに効く」と読めます。変更の履歴は 重みの変遷。
