よくある混同: 2023年版と2026年版

検索上位の解説には、2023年の Heavy Ranker の重みと、2026年の xai-value-model の重みが混ざっているものがあります。別のシステムなので混ぜると誤解します。

2026年版には「著者が返信に返信」という重みはありません。返信は行動確率として Phoenix が予測し、値モデルでは 5.0 の重みで扱われます。

上流 README が否定している誤解

「報告1件 = いいね468件分」は誤り。
重みは確率に掛かるもので、生のカウントには掛かりません。報告の重み −234 は「あなたが報告する確率」に掛かります。報告確率はいいね確率より1000倍以上低いため、大きな重みが付いています。

この注意は上流の README と scoring.rs のコメントに明記されています。
