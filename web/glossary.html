用語

スコア計算に出てくる用語を、意味と「数字でどう現れるか」で説明します。

P(行動)（行動確率）
その閲覧者がその行動をする確率。0〜1。例: 表示100回で返信2回なら 0.02。このサイトでは公開カウント÷表示回数で代用。
重み（weight）
行動確率に掛ける倍率。例: 返信 5.0、いいね 0.5。確率1.0あたりの寄与を表す。カウントには掛からない。
寄与（contribution）
重み × P(行動) の値。例: 5.0 × 0.016 = 0.080。スコアの内訳の1行分。
combined（重み付き和）
全行動の寄与の合計。offset を通す前の値。
offset（オフセット）
負の combined を 0〜0.001 に圧縮する処理。正の combined には 0.001 を足す。NEGATIVE_SCORES_OFFSET = 0.001。
positive_sum / negative_sum / total_sum
offset の計算に使う重みの合計。10月は 43.24 / 371.54 / 414.78。
unoffset_score
offset の逆変換。offset 後の weighted score から元の combined に戻す。MultiplierPreOffset 分岐で使う。
author diversity（著者多様性）
同じ著者の2件目以降に掛かる減衰。(1−floor)×decay^position + floor。既定 decay 0.5 / floor 0.25 で、2件目は 0.625 倍。
position
同じ著者の何件目か（0始まり）。1件目は position 0 で倍率 1.0。
OON（out-of-network）
フォロー外の投稿。既定で 0.75 倍に割引。トピック経由は 0.5 倍、新規ユーザーは 0.00001 倍（閾値0秒の既定では発火しない）。
in-network
フォロー中などネットワーク内の投稿。OON の割引を受けない。新規性（post_unexplored）の加点も in-network のみ。
VQV（video quality view）
動画の視聴品質。10秒超のときだけ重みが適用される（duration gate）。既定重みは 0.0 なので現在は空振り。
cdwell（クリック後滞在）
クリックしてから滞在した時間。10月から重み 0.4 が直接適用される。
MultiplierPreOffset
多様性/OON を offset の前に掛けるか。既定 false（後で掛ける）。
weight perturbation（重みの揺らぎ）
viewer ごとに重みを exp(±σ) で揺らす仕組み。既定 σ=0.0 で無効。
cached weighted score
一度計算した weighted score を再利用する仕組み。9月は param で制御、10月は値があれば使う形に統合。
Phoenix
行動確率を予測するモデル。閲覧者の行動履歴と候補投稿を Transformer に入れて P(action) を出す。
Home Mixer
候補の取得・除外・スコア付けを行う本体パイプライン（Rust）。
value model / VM ranker
スコアの数式（xai-value-model crate）と、それを動かすランキングサービス（vm-ranker）。公開既定値は vm-ranker/params.rs。
action space
予測する行動の種類数。公開値は 60 discrete / 64 padded / 8 continuous。
model profile
Phoenix のモデル寸法。例: xrecsys_seqpack は emb 2560、8層、query heads 20。
hydration（ハイドレーション）
候補に著者属性・投稿属性・安全ラベルなどを付ける段。
出典: xai-org/x-algorithm の公開既定値（upstream_2026_10 / 76843a5eea）
